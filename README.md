# Dashboard Inflasi Bulanan 2025

Dashboard Power BI yang menampilkan inflasi bulanan (M-to-M) 38 provinsi di Indonesia (2022=100), kelompok Makanan, Minuman dan Tembakau, tahun 2025.

![Dashboard Inflasi](Inflasi%20Bulanan%20Tahun%202025_page-0001.jpg)

## Isi dashboard
- Kartu ringkasan: inflasi nasional, inflasi kumulatif, dan provinsi tertinggi
- Tren inflasi bulanan nasional (line chart)
- Perbandingan inflasi 38 provinsi (bar chart)
- Tabel rekap bulanan dengan warna deflasi dan inflasi
- Slicer untuk memilih kelompok dan periode

## Key insight
1. Inflasi tertinggi di Januari (1,94%) dan Desember (1,66%), deflasi terdalam di Mei (-1,40%).
2. Akumulasi setahun sekitar 4,54%, terutama didorong harga makanan. Rokok stabil naik tiap bulan.
3. Aceh paling tinggi (sekitar 12,2%), Sulawesi Utara paling rendah (sekitar 1,2%). Lima provinsi teratas semuanya di Sumatera.

## Sumber data
Badan Pusat Statistik (BPS), Inflasi Bulanan (M-to-M) 38 Provinsi (2022=100) Menurut Kelompok dan Sub Kelompok 01 Makanan, Minuman dan Tembakau, 2025.
